# Building Streamlit UI and Real-Time Simulation Module

## Real-Time-UPI-Fraud-Detection-System

### Module Overview

The Building Streamlit UI and Real-Time Simulation Module is the final deployment layer of the Real-Time-UPI-Fraud-Detection-System. This module integrates all previous pipeline components and provides an interactive web-based dashboard for monitoring, analyzing, and detecting potentially fraudulent UPI transactions in real time.

The dashboard allows users to:

* Simulate live UPI transactions
* Monitor anomaly scores
* Detect suspicious transactions instantly
* Visualize fraud analytics
* Explore model performance metrics
* Analyze transaction behavior patterns

The module combines:

* Synthetic transaction generation
* Feature engineering
* Isolation Forest inference
* Optimized threshold-based fraud decisions
* Interactive Streamlit visualizations

into a unified real-time fraud monitoring application.

---

# Business Problem

Modern digital payment platforms process thousands of transactions every second.

Fraud detection systems must:

```text
Detect suspicious activity quickly

Minimize false alarms

Provide actionable insights

Support fraud analyst investigations
```

Traditional batch-based fraud detection systems often introduce delays.

This module enables:

```text
Real-Time Transaction Monitoring

Real-Time Fraud Alerts

Interactive Investigation Dashboard
```

allowing stakeholders to identify and respond to suspicious activity immediately.

# Real-Time Fraud Detection Pipeline

For every incoming transaction:

### Step 1

Generate behavioral features.

### Step 2

Scale features using:

```text
scaler.pkl
```

### Step 3

Generate anomaly score using:

```text
Isolation Forest
```

### Step 4

Apply optimized threshold.

### Step 5

Display prediction.
